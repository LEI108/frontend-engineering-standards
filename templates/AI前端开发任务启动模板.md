# AI 前端开发任务启动模板

> 复制本模板到任务对话并填写。它传递上下文和授权，不替代正式规范。

## 任务信息

```text
项目路径：
当前分支（未知则检查）：
任务阶段：分析 / 方案 / 实现 / 静态验证 / 运行验证 / 视觉验收
任务目标：
用户可见验收：
明确不做：
允许的写操作：
commit / push / 部署授权：未授权 / 已单独授权
已确认合同：
待确认事项：
```

## 启动指令

```text
请先读取并遵守：
1. 当前项目及适用子目录的 AGENTS.md；
2. 正式前端开发规范/standards/前端工程开发规范（通用版）.md；
3. AI 参与时读取 standards/AI前端协作与分层验证规范.md；
4. 与项目技术栈匹配的 Profile 和项目技术基线；
5. guides/规范与技能条件引用向导.md，并只加载本任务需要的 Skill；
6. 目标路由、组件、API、类型、状态、样式、测试和当前 Git 差异。

先检查工作区并区分用户已有修改。追踪真实调用链，不猜接口、权限、设计值和运行结果。
修改前给出最小变更地图：文件与语义锚点、保留行为、新行为、合同、风险和验证。
只在上方授权阶段内行动；未授权的 commit、push、部署和外部写操作不要执行。
```

## 交付格式

```text
结果摘要：
修改文件与行为：
实际执行的静态检查：
实际执行的测试/构建：
运行验证：
浏览器/视觉/交互验证：
真实后端或外部验证：
未完成与风险：
人工审核状态：
```

没有执行的层级写“未完成”或“不适用”，不得用 build 成功代替运行、视觉或真实后端验收。
